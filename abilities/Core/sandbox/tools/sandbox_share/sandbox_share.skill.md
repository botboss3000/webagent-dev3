# sandbox_share

## Usage

- Operators only: share one of your saved UI elements with every user of this agent (`shared: true`), or stop sharing it (`shared: false`).

Sharing copies your element as it is now; after changing your copy, share it again to update the shared one. Other users see the shared element read-only and can present it in their chats. Share only when the operator asks; in Ask mode they approve it in the chat.
