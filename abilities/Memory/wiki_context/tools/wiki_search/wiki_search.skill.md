# wiki_search

## Usage

- Search the shared server Wiki by keywords across titles, tags, keywords and bodies.
- Pass synonyms and other phrasings of the query in also; articles matching more of them rank higher.
- Returns slugs, titles and excerpts, best match first.
- Search before answering from or writing to the Wiki.

Takes `query` and `also`. Search matches words, not meaning, so put synonyms and other phrasings in `also` (for "refund": money back, reimbursement, return policy).
