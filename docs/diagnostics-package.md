# Native Diagnostics package

Diagnostics follows the trusted native package model of Codebase Admin. Its five public tools and existing internal aliases retain core Rust schemas and authority. Generic isolated packages never receive browser credentials. The native worker bridge alone forwards trusted current-session metadata over private stdin; package argv/environment/results contain no cookie.

plugin.json interface 1 declares runner.py and adapter.py as executable inputs. The private transport uses bounded newline-delimited JSON protocol 1, invocation IDs and a result object. runner.py maintains observations and recording between calls. Two browser processes are admitted globally, serialized per session; artifact reads are stateless and do not consume admission. Each browser pins its release and full executable digest until close, idle expiry (180 seconds) or authorization expiry (at most 600 seconds). Release retention exceeds that lease. Quiescence kills the owned process group; restart does not restore profiles or replay input.

The initial worker/native-loader/provisioning integration needs an engine release. Subsequent compatible package updates use plugin_deploy and the retained API-image interpreter and package tests. The manifest/tool interface is fixed; incompatible changes require coordinated installation. Development API process/thread capacity is set to 1024 through the protected installation configuration's api_pids_limit. Validation accepts integers from 256 through 4096; omitted legacy configurations retain 256 until explicitly reconfigured. lifecycle.py reconfigure applies a changed budget to only the API using retained images, and subsequent broker image releases adopt that protected budget. Loop, gate, memory, listener and storage settings are preserved.

Startup, authentication, capacity, invalid requests, backend failure and transport interruption use bounded error_kind values. Raw exceptions, cookie data and unrestricted driver logs are never published. Screenshot/recording formats and authenticated artifact routes are unchanged.
