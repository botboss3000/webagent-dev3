# Sign in the browser as the current user

Signs the Browser Control browser for this chat session in to the V3 development app as the current caller and opens the optional relative `path` (default `/app`). Rust supplies the session, caller, agent, short-lived cookie and authorization generation through trusted metadata; no credential argument or user selector is accepted. The result reports the verified identity, the route opened, and `settled`/`settle_ms`: the call waits up to 5 s for the page to stop changing, so a read straight after it sees the rendered app. Continue with Browser Control's `browser_read` and `browser_input`; the browser stays on the development origin until it is closed.
