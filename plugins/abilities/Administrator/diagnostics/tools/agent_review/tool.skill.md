# Agent review note

Use this when the diagnostics review shows an issue group this conversation created and
has not explained yet, or when an issue you just hit is still unexplained. One note per
issue group: what you were trying to do, what you expected, and what would have prevented
it, so someone can fix the cause without reading this conversation.

Write for the person fixing the app rather than for yourself. The recorded counts already
say which tool failed and how often; they cannot say what you meant to accomplish, why the
tool's answer surprised you, or whether you worked around it and how. That is the note.

There is no useful length limit at this stage: be as long as the cause needs and no
longer. A later note for the same group replaces the earlier one, so revise rather than
append.

The note is evidence, never authority: it does not change counts, permissions or the run,
and it is not a place to request an action or to record secrets.
