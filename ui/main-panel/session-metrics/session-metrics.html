Metric definitions

Total Turns
Model calls in the run (run record / usage reported calls). One turn can emit several tool calls in parallel, so tool calls can exceed turns.
Total Tool Calls
tool_call events in the run interaction log; each has exactly one tool_result. Failed Calls counts results in error; Retry Calls counts repeated calls made for the same step.
Total Messages
All interaction-log events for the run: tool calls + tool results + reasoning (diagnostic) entries + step ends. Visible chat messages are separate (Trial 5: 3).
Processes
The run segmented into work processes, with the turns spent in each. Setup & begin: load abilities and begin the isolated build task. Discover files: directory listings to locate the right files. Understand code: file reads to learn the existing patterns. Prepare patch: compose the change. Apply patch: submit it for validation and apply. Publish: progress messages to the session. Build / release: build status and finish, including validation and the UI release switch. Close & report: final status and the summary message.
App Steps
Completed agent step boundaries (agent_step_end events) in the interaction log.
Data source
Run interaction log API: GET /api/v3/sessions/{session_id}/runs/{run_id}/logs (paged, 100 events per page). Cost is shown only when the provider reports it.
